# 同误报点与反转机制：追加分析协议

本轮在confirmation-v01结果已暴露后制定，不属于新的确认性研究。保留原实验及其全部阈值；追加输出到`experiments/fp_mechanism_v01`。不重新训练、不下载新数据、不选择有利录制组。

固定四个完整组、三套权重、20%位置容量和共同查询。九个条件为dense、EMA current、EMA absolute、lag3 current、当前活动、历史活动、persistence absolute、空间滚动EMA absolute和无符号残差。最后一项仅修改排序公式，不改变候选、特征或循环状态。

同误报分析预定0.25、0.5、1、2 FP/query，主工作点为1。先从最低置信度0.01的实际NMS输出确定阈值，再在每个报告阈值重新运行上游NMS和一对一匹配；不假设含相同分数的NMS天然满足前缀不变性。若实际FP超出整数上限，依据实际FP分数提高阈值并复核。达到范围、剩余预算、同分数跳变全部报告，不插值制造分数检测。

两种制度分别报告：Thun选阈值后直接迁移；在已经暴露的评价片段上选阈值的回顾性同FP预算诊断。后者不是可部署阈值的泛化证据。只有实际FP差不超过max(1, floor(1%目标FP数))、且双方均未超预算，才将该配对称为误报匹配；其余点标记未匹配。主任务指标是完整GT召回，同时报告固定原dense参考的证据保留、TP、FP和实际FPPI。不能只选Q较有利的结论。

机制分析固定完整检测头输出，以原dense匹配框的原始anchor/site定位其证据来源，区分残差独选、活动独选、共同选与共同不选，检查源位置覆盖能解释多少实际保留差、多少受NMS／替代候选影响。记录各查询分数与检测头置信度的秩相关，以及填充区和GT框中心占用；非dense支持位置不能直接称为背景。

以同一观察特征H和因果EMA预测P计算M=sum|H|、B=sum|P|、同符号重叠O=sum min(|H|,|P|)，验证N=sum|H-P|=M+B-2O。无符号残差sum||H|-|P||仅移除相反符号贡献，可检验符号变化是否是必要解释；空间滚动保留历史特征值分布但打破局部对应，可检验时空对应的作用。不同架构输入／预训练／分辨率／状态同时不同，本轮不把架构标签当成单一原因。
